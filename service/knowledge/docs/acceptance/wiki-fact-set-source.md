# Wiki 完整来源事实清单 v1：RTW 源候选交接

状态：**默认关闭的开发候选**。RTW 已有 `knowledge.wiki.quality.judged.v1` 每次只判断一个 `(wiki_revision_id,fact_id)`；到达的判断数不能推出一页还应覆盖哪些事实。`FactSet` 是管理员对一个不可变 Wiki 修订与获准来源范围作出的版本化**完整性声明**。RTW 能确定该来源范围并核每条所列事实的原字节，却不能自动发现管理员漏列的事实；真人 FactCatalog 复核和实时 UserCenter 管理员撤销资格不在本版。`actor_id` 仍是现有 Auth JWT 与 `AdministratorIDs` 名单允许的原 `userId` 字面值，允许名称如 `test-admin`，不得填作规范 UID，也不加 tenant。

## 范围与版本

管理员 POST 固定 `module_id,page_id,wiki_revision_id`，提交按 RevisionID 严格升序的 `source_revisions[{revision_id,content_sha256}]`、1–128条 `facts[{source_revision_id,locator,source_quote,source_quote_sha256,required,conflict_group}]`、`facts_complete=true`、`reason,base_fact_set_revision_id,idempotency_key`，AI目标可给 `origin_compile_id`。AI Wiki 必须回读 `created_by=btw.compile/<id>` 与 RTW `ACCEPTED` Compile，来源清单**逐项等于** Compile 全部冻结 SourceRevisionID；当前 Wiki 只引用其中一部分不能缩小事实范围，任一冻结来源撤回即拒新清单。人工 Wiki 的获准范围是当前页 SourceRefs、同页不可变 base 链的 SourceRefs 与链上 AI 已接纳 Compile 全部 SourceIDs 的规范并集；未撤回的祖先来源一个不能任意删。只有 RTW 正式撤回过的**祖先**资料会退出新的当前范围；若当前人工 Wiki 自己仍引用撤回资料，则新清单拒绝。旧清单、旧评阅与原 Event 保持原范围/对象/字节，不回填或改写。

每个 SourceRevision原对象需是有效 UTF-8 `text/plain|text/markdown`，对固定 ContentSHA/`sha256/<hash>`读回；v1来源数上限64、原对象合计64MiB。每个 Fact须在其真实 `paragraph:N`段中有原句精确字节。`source_byte_start/end`指**引文自身**在Source原 UTF-8对象的绝对字节范围，重复引文固定该段首次匹配，CRLF/四空格不能被 TrimSpace 重定位。RTW 服务端沿旧质量合同派生同一个 `fact_id=fact_<SHA256(SourceRevisionID NUL locator NUL quoteSHA)>`，而非客户端ID；同一清单FactID不可重复。至少一条事实为 `required=true`，非空 `conflict_group`只接纳至少两条不同FactID组成的人工矛盾组。组名是关系标识，不是模型置信度或D07阈值。

`source_scope_revision=scope_<RFC8785 JCS SHA256({module_id,page_id,source_revisions})>`只由服务对规范完整来源集合派生，不含当前 Wiki 修订；按 `(module_id,page_id,source_scope_revision)`保留一个独立 FactSet head。管理员为同来源范围的新Wiki修订重冻时必须带 head 当前`base_fact_set_revision_id`，同事务追加新 `fact_set_revision_id`与规范十进制`fact_set_revision`，旧目录可按ID回读。GET `/fact-sets/:source_scope_revision`仅是**该范围当前head**；历史 AI/人工目标必须 GET `/fact-set-revisions/:fact_set_revision_id`，并复核返回的 WikiRevisionID、来源范围与 FactSet JCS，不从最新head/活动Release猜历史。新来源范围另起独立head；FactSet/head事务不写 `knowledge_heads` Wiki编辑指针或管理员Release活动指针。
